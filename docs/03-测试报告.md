# 功能测试报告

## 测试环境

- 当前系统：本机 Linux 环境
- 后端：FastAPI + SQLite
- 前端：Vue 3 + Vite
- LLM：默认 `LLM_MODE=mock`，DeepSeek API Key 留空

## 测试项

| 编号 | 测试内容 | 方法 | 预期 |
| --- | --- | --- | --- |
| T1 | 手册索引存在 | `python scripts/smoke_test.py` | `index_count > 0` |
| T2 | 文本检索 | 查询“火花塞怎么检查” | 返回手册片段和页码 |
| T3 | RAG 问答 | `/api/ask` 或前端智能诊断 | 返回答案、引用、置信度、风险等级 |
| T4 | 作业指引 | `/api/workflow` | 返回步骤、工具、安全项、进度规则 |
| T5 | 案例审核入库 | 上传案例并审核通过 | 写入检索库和图谱 |
| T6 | 图片上传限制 | 上传非图片或超大文件 | 返回 415 或 413 |
| T7 | 前端构建 | `npm run build` | 生成 `frontend/dist` |

## 本机快速验证

```bash
cd /data/xli/softcup
source backend/.venv/bin/activate
python scripts/smoke_test.py
cd frontend && npm run build
```

## 已知边界

- mock 模式不进行真实视觉理解，只使用占位图片描述。
- DeepSeek API Key 需由部署方在 `.env` 中填写。
- 当前版本暂未在 LoongArch + 银河麒麟环境验证。
