# 运行部署说明

## 本机开发运行

```bash
cd /data/xli/softcup
python3 -m venv backend/.venv
source backend/.venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env
python scripts/ingest_pdf.py --force
./scripts/dev.sh
```

访问：

- 前端：`http://127.0.0.1:5173`
- 后端 API：`http://127.0.0.1:8000/docs`

## DeepSeek API 模式

编辑 `.env`：

```env
LLM_MODE=api
LLM_API_BASE=https://api.deepseek.com/v1
LLM_API_KEY=
LLM_API_MODEL=deepseek-chat
```

`LLM_API_KEY` 提交作品时保持空白，由运行环境注入。

## 单端口运行

```bash
cd /data/xli/softcup
./scripts/build.sh
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 `http://127.0.0.1:8000`。

## 数据目录

- `data/search.db`：手册与案例检索索引
- `data/app.db`：案例、标注、图谱
- `data/uploads/`：用户上传图片

## 资源控制

- 默认检索使用 SQLite FTS5，无需外部向量库。
- 默认 `LLM_MODE=mock`，不会加载大模型。
- API 模式只传入截断后的检索上下文，降低网络与 token 开销。
